| CTA | 24 chars | 20 chars | Verb first |

Chinese counts use CJK glyphs as one unit. Validate final strings against `docs/copy-fields.json` in CI.

**Mobile variants:** when the canonical desktop phrase cannot meet the mobile limit, `copy-fields.json` provides `enMobile` / `zhMobile` layout variants. The desktop string remains the canonical copy; the mobile variant must preserve the same meaning and claim markers. `node scripts/validate-copy.mjs` checks both.
